# 项目方向与首个开发阶段

本文保留最初策划摘要。后续设计讨论以 [GDD v0.2 创意扩展版](XJT_GDD_v0.2.md) 为入口。

依据用户提供的《策划案.docx》整理。原文件保留在用户本地，本仓库记录开发摘要。

## 核心体验

在媒介构成的世界中，通过 2D 平台跳跃体验从感知到视觉过载的过程。媒介干扰改变玩家的视觉判断，并进一步影响其行动。

## 策划机制

- 跳跃过程中间歇触发闪白，短暂插入广告图像。
- 闪白后平台发生少量偏移，平台漂移方向由箭头提示。
- 后续逐渐叠加新闻标题弹幕、广告图像、名人面部特写。
- 文字弹幕具有轻微物理推力，可以推开玩家。
- 流程包含普通平台、闪白与漂移平台、文字干扰、通关；掉落后死亡并重新开始。

## 建议实现顺序

1. 固定侧视相机、左右移动、跳跃、基础碰撞、掉落重生。
2. 搭建可以从起点到终点完成的短关卡。
3. 增加单次闪白、占位图像、方向提示及平台偏移。
4. 增加文字移动和推力，调节跳跃难度。
5. 补充多层视觉素材、音效、结束界面和打包验证。

## 当前边界

目前只建立项目基础和灰盒场景，以上玩法均为后续工作。画面参考用于明确拼贴、信息叠加的方向；具体美术素材尚未导入。项目技术名暂用 XJT，游戏正式名称未定。
